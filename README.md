# MG 私桩 · 网页版（iPhone / Android / 桌面）

用蓝牙直接控制 **MG（上汽）私桩**的网页版客户端。单文件、零依赖、不联网、不上传任何数据。

> 协议逆向自 MG 私桩 APK（包名 `local.mglive.piledebug`）内的 Web Bluetooth 页面，该页面注释自称移植自 MG Live 2.2.6。
> **非官方工具**，请只操作你拥有或获准使用的充电桩。

---

## 打开就能用

| 设备 | 浏览器 |
|---|---|
| iPhone / iPad | **Bluefy – Web BLE Browser**（App Store 免费）。Safari 不支持 Web Bluetooth，用 Safari 打不开蓝牙 |
| Android | Chrome |
| 电脑 | Chrome / Edge |

**必须是 https 地址**（Web Bluetooth 只在安全上下文可用）。

## 功能

- 读取充电桩状态：桩号、充电状态、灯光、提示音音量、预约时段
- 控制：开始充电 / 停止充电 / 立即充电（未到预约时间强制启动）
- 灯光开关、提示音音量设置
- 预约充电设置与关闭（0xB3）
- 桩时钟校时（0xB0）
- VIN 认证（桩索要时写 FFF6）、桩号一致性校验
- 通信日志 + 一键导出（含全量十六进制，便于排查）
- **诊断**：接收帧头 0x68/0xAA 兼容开关、环境自检、协议自检

## 协议速查

服务 `FFF0` ｜ 写 `FFF3` ｜ VIN `FFF6` ｜ 通知 `FFF4 / FFF5 / FFF9`

```
发送帧: 68 | cmd | 00 00 | lenL lenH | 00 | XOR | payload...   （全帧异或 = 0）
接收帧: AA | cmd | 00 00 | lenL lenH | 00 | XOR | payload...   （本版默认也接受 68）
```

| cmd | 功能 | payload |
|---|---|---|
| 0xA0 | 灯光 | `[on?1:0, 1, 0,0,0,0,0]` |
| 0xB0 | 校时 | uint32 秒（小端） |
| 0xB1 | 系统信息 | 空 |
| 0xB2 | 音量 | `[0..100]` |
| 0xB3 | 预约 | 开 `[1,sh,sm,eh,em]` / 关 `[0,0,0,0,0]` |
| 0xB4 | 开始充电 | `[1,0]` |
| 0xB6 | 停止充电 | `[0]` |

0xB1 响应（≥59 字节）：桩号 `p[0..19]`、灯光 `p[41]`、预约模式 `p[46]`、预约时刻 `p[47..50]`、音量 `p[51]`、状态 `p[58]`。
状态：0/2 未充电，6 充电中，8 充电完成，9 离线。FFF5 信令：`0x0A` 索要 VIN、`0x55` 不匹配、`0x54` 超时。

## 自检

```bash
node verify.js
```

输出 8 条黄金向量比对、帧解析器回归、外部资源检查，全过则打印 `RESULT: ALL PASS`。
页面里也有「协议自检」按钮，离线可用。

## 已知未确证项

1. **上下行帧头不对称**（发 0x68 / 收 0xAA）是原实现的硬编码，无实机证据；本版默认同时接受两者，可在页面切换。
2. **结果码语义**：原实现把 `payload[0]==0` 当成功，属推测；0xB6 不做结果码校验。
3. **0xB5（状态推送）、0xB8（累计充电）未实现**；状态靠 5 秒轮询 0xB1，固件版本/累计电量读不到。
4. 认证失败（VIN 不匹配或桩号不匹配）后会话内不可恢复，需断开重连。
5. 日志包含桩号与全量 RX 十六进制，分享前自行检查。
