iPhone 该用哪个浏览器？

iPhone / iPad：用 Bluefy – Web BLE Browser（App Store 免费）打开本页。Safari 至今不支持 Web Bluetooth，直接用 Safari 打不开蓝牙。

Android：Chrome 打开。电脑：Chrome / Edge 打开。

必须满足：页面地址是 https://… 或 localhost（安全上下文）。用 http:// 或直接双击本地文件打开时，浏览器不会提供蓝牙能力。

连接不上时按顺序排查
  1. 确认已授予「蓝牙」权限；Android 12+ 另需「附近的设备」，Android 11 及以下需打开系统定位开关。
  2. 离充电桩近一些（2–3 米），桩要处于可被连接状态，且没有被别的手机占用。
  3. 看下方「通信日志」：若出现 丢弃非 AA/68 帧头数据，说明桩返回的帧头与预期不符，到「诊断与兼容」里切换帧头模式。
  4. 若日志里一条 RX 都没有，通常是通知特征没订阅上（桩未暴露 FFF4/FFF5）。

连接条件与认证说明

此 APK 使用手机原生蓝牙，无需浏览器、电脑或网络。服务 FFF0，指令 FFF3，VIN FFF6；监听 FFF4 / FFF5 / FFF9。VIN 校验失败会停止发送控制指令。桩号有填写时，系统信息返回的桩号必须匹配。只拥有 UUID 不代表已经认证。

未到预约时间，立即充电？

将关闭充电桩的预约，确认关闭后发送启动指令。原预约不会自动恢复；下次需要重新设置。

如果车辆本身设置了预约，桩端不能代替车辆解除预约；部分桩也可能需要重新插枪。
